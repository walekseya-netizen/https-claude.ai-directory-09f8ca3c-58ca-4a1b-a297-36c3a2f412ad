# Сервис формирования КС-2 и КС-3

HTTP-сервис для выпуска первичных документов строительного подряда:

* **КС-2** — акт о приёмке выполненных работ (ОКУД 0322005);
* **КС-3** — справка о стоимости выполненных работ и затрат (ОКУД 0322001).

Формы соответствуют постановлению Госкомстата России от 11.11.1999 № 100.
Сервис считает стоимость работ, НДС и нарастающие итоги, хранит документы
и выгружает их в XLSX, готовый к печати и подписанию.

## Возможности

* расчёт акта КС-2 по позициям сметы: количество × коэффициент × цена, округление до копеек;
* режимы НДС: начисление сверху по ставке (20 %, 10 %, 5 % и др.) и «без НДС» (УСН, ст. 145 НК РФ);
* автоматическое формирование КС-3 по ранее сохранённым актам КС-2 с нарастающими
  итогами «с начала проведения работ» и «с начала года» (при переходе года графа
  «с начала года» обнуляется);
* группировка строк справки по объектам, по актам или одной строкой;
* ручное формирование КС-3, если суммы ведутся вне сервиса;
* выгрузка обеих форм в XLSX (Times New Roman, A4, печать на одну страницу по ширине);
* предпросмотр расчёта и файла без сохранения в базе;
* контроль непротиворечивости: единый договор, подрядчик, заказчик и ставка НДС в рамках одной справки.

## Стек

Python 3.11, FastAPI, Pydantic v2, openpyxl, SQLite. Внешних сервисов не требуется.

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
```

Документация API: <http://127.0.0.1:8000/docs>, проверка живости: `GET /health`.

Через Docker:

```bash
docker build -t ks-service .
docker run -p 8000:8000 -v "$PWD/data:/data" ks-service
```

Путь к базе задаётся переменной окружения `KS_DATABASE_PATH` (по умолчанию `data/ks.sqlite3`).

## API

| --- | --- | --- |
| `POST` | `/api/v1/ks2` | Сформировать и сохранить акт КС-2 |

| `POST` | `/api/v1/ks2/preview/xlsx` | Получить XLSX акта без сохранения |
| `GET` | `/api/v1/ks2` | Список актов (фильтры `contract_number`, `period_from`, `period_to`, `limit`, `offset`) |
| `GET` | `/api/v1/ks2/{id}` | Акт по идентификатору |
| `GET` | `/api/v1/ks2/{id}/xlsx` | Выгрузка акта в XLSX |
| `DELETE` | `/api/v1/ks2/{id}` | Удалить акт |
| `POST` | `/api/v1/ks3/from-acts` | Сформировать справку по актам КС-2 |
| `POST` | `/api/v1/ks3/from-acts/preview` | Рассчитать справку по актам без сохранения |
| `POST` | `/api/v1/ks3` | Сформировать справку по заданным строкам |
| `GET` | `/api/v1/ks3` | Список справок |
| `GET` | `/api/v1/ks3/{id}` | Справка по идентификатору |
| `GET` | `/api/v1/ks3/{id}/xlsx` | Выгрузка справки в XLSX |
| `DELETE` | `/api/v1/ks3/{id}` | Удалить справку |

### Пример: акт КС-2

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/ks2 \
  -H 'Content-Type: application/json' \
  -d @examples/ks2_request.json
```

Ответ содержит рассчитанные строки и итоги:

```json
{
  "id": "0f2c…",
  "form": "KS-2",
  "okud": "0322005",
  "items": [
    {"number": 1, "name": "Устройство монолитных железобетонных стен", "amount": "1060569.13"},
    {"number": 2, "name": "Кладка наружных стен из керамического кирпича", "amount": "339605.70"}
  ],
  "totals": {
    "net": "1400174.83",
    "vat": "280034.97",
    "gross": "1680209.80",
    "vat_mode": "charged",
    "vat_rate": "20"
  }
}
```

Файл акта:

```bash
curl -OJ http://127.0.0.1:8000/api/v1/ks2/0f2c…/xlsx
```

### Пример: справка КС-3 по актам

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/ks3/from-acts \
  -H 'Content-Type: application/json' \
  -d '{"act_ids": ["0f2c…", "a41b…"], "document_number": "1", "document_date": "2026-04-30"}'
```

Справка за следующий период строится поверх предыдущей — достаточно передать
`previous_certificate_id`, и графы «с начала проведения работ» и «с начала года»
заполнятся автоматически. Если работы начались до внедрения сервиса, начальные
накопленные суммы передаются в `opening_balances` (см. `examples/ks3_from_acts_request.json`).

## Правила расчёта

* Все суммы — `Decimal`, округление до копеек по правилу «половина вверх»
  (`ROUND_HALF_UP`). В JSON суммы передаются и возвращаются строками, чтобы
  не терять точность на стороне клиента.
* Стоимость строки акта: `количество × коэффициент × цена`, округляется до копеек;
  итог акта — сумма уже округлённых строк (как в печатной форме).
* Если коэффициент отличается от единицы, он выводится в наименовании работ
  («…(с коэффициентом 1,15)»), чтобы печатная форма оставалась арифметически проверяемой.
* НДС начисляется сверху на итог без НДС. В режиме `"vat_mode": "none"` ставка и сумма НДС
  равны нулю, а «Всего с учётом НДС» совпадает с итогом.
* В КС-3 НДС считается отдельно по каждой графе: с начала работ, с начала года и за период.
* Строка справки проверяется на непротиворечивость:
  `за период ≤ с начала года ≤ с начала проведения работ`.

## Структура проекта

```
app/
  api/            HTTP-эндпоинты (КС-2, КС-3, служебные)
  domain/         модели, расчёт, денежная арифметика, ошибки
  export/         выгрузка унифицированных форм в XLSX
  storage/        хранилище документов на SQLite
  config.py       настройки из переменных окружения
  main.py         сборка приложения FastAPI
tests/            тесты расчёта, API и выгрузки
examples/         примеры запросов
```

## Ограничения

* Аутентификация и разграничение доступа не реализованы — сервис рассчитан на
  размещение за внутренним шлюзом.
* Выгрузка только в XLSX; PDF при необходимости получается конвертацией
  (например, LibreOffice в headless-режиме).
* Сметные расценки не нормализуются: цена за единицу передаётся клиентом.
